# Contributing

We welcome concise, platform-neutral improvements. Please open an issue first for substantial changes to policy, CI, verification behavior, or security. Pull requests must explain scope, risks, actual tests, and tests not run. Never submit secrets, customer data, paid third-party assets, or private application source.

Changing a guardrail deserves **more** review than a routine documentation fix. Contributors must not disable tests, remove checks, or weaken required approvals merely to make CI pass.

This repository does not ask contributors to run untrusted commands or provide production credentials.
