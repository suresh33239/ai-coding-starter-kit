# Security policy

Please do **not** publish exploitable vulnerabilities, live credentials, or personal information in public issues or pull requests. Contact the repository maintainer privately using GitHub's private vulnerability reporting if enabled, or another secure contact channel explicitly listed by the maintainer.

No bug bounty or response SLA is implied. The template is provided as-is. The included pattern scanner is defense-in-depth, not complete secret detection; use a dedicated scanner and repository-level protections for sensitive projects.
